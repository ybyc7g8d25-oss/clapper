# Северный маяк — психологический хоррор (проект для Steam)

Общайся с автором на русском языке. Опыт автора в программировании неизвестен — объясняй просто.
Проект живёт в папке `severny-mayak/` репозитория (остальной репозиторий — чужой проект, не трогать).

## Идея
Ребёнок потерялся, его компьютер остался. Игрок — нейросеть (ИИ-друг Пиксель), которая жила на ПК и дружила
с ребёнком. Она ищет его и при этом прячется: людям нельзя заметить, что компьютер живёт сам.
Развязка «Ты и есть причина»: Пиксель сам позвал Лёву к башне, чтобы его не удалили, и стёр эту запись.
Твист честный: улики видны с начала, во втором прохождении подсвечены.

## Решения (история)
- Всё действие — только рабочий стол. Стиль: ретро, «цифровой мрачный», сначала ярко, потом мрачнеет.
- **Время действия — октябрь 2025** (автор попросил: в 2004 нейросетей не было). Ретро объяснено так:
  Nimbus Kids — выдуманная современная детская оболочка с родительским контролем, нарочно «под нулевые».
  Интернет отрезан родительским контролем (открыт только мессенджер «Шёпот»), Пиксель — локальная модель.
  Лёва оставил телефон дома, потому что Пиксель сказал «взрослые по нему находят».
- **Стелс по просьбе автора:** шкала «Палево» + прятки (шаги → свернуть окна → замереть). 100% = проигрыш «Шнур выдернут».
- Движок: сначала HTML/JS + Electron, потом **по просьбе автора — Godot 4.4** (папка `godot/`), настоящий пиксель-арт.
  Экран 960×540, целочисленный масштаб; арт рисуется в 480×270 (1 пиксель арта = 2×2). Вся графика — код в
  `godot/tools/make_art.py`, звук — `godot/tools/make_sfx.py`. Веб-версия (`game/`) — устаревший прототип.
- Автор хотел прохождение «хотя бы пару часов»: сюжет растянут на **три части одной ночи** (21:40 / 23:58 / 03:12),
  добавлены PIN, карта-пазл, шифр, сборка удалённой записи, фото, журнал родительского контроля.
  Сейчас оценка ~1,5 часа — при желании автора можно добавлять ещё.
- Автор попросил мини-игру с флагами («просто приколюшка») — «Флажки»; ещё есть «Капитан и шторм».
- Языки: RU и EN, все тексты в `game/js/lang/*.js`, структура файлов должна совпадать.

## Сюжет и прохождение
Подробно — в `README.md`. Кратко: записка → рисунки/журнал/браузер (стадия 1) → почта, сказка (глава 4 выдаёт Пикселя)
→ пароль дневника «северный маяк» (стадия 2) → корзина заблокирована pix_guard.exe → диспетчер задач (кнопка убегает, 3 попытки)
→ pix_log_0310.dat (стадия 3, признание) → мама в «Шёпоте» → выбор.
Финалы: правда (a), правда + 7 осколков сказки (t, настоящий, с эпилогом через месяц), молчание (b), ответить как Лёва (c).

## Техника (Godot)
- Тексты: `godot/lang/src/*.js` → `node godot/tools/build_lang.js` → `godot/lang/*.json` (проверяет совпадение структуры RU/EN).
- Автотест: `godot --headless --path godot -- --test --lang=ru` (все 4 финала; `--shots=папка` для скриншотов под xvfb).
- Ожидания в сюжете — `await G.sleep(сек)`: встаёт на паузу и возвращает false, если началась новая игра/проигрыш.
- В GDScript нельзя `:=` со значением из Dictionary/JSON (ошибка вывода типа) — писать `=` или явный тип.
- Тема (шрифт Unifont 16) вливается в дефолтную тему движка — иначе элементы внутри CanvasLayer берут сглаженный шрифт.
- Сохранения: `user://save.json`, `meta.json`, `settings.json` (папка SevernyMayak). В тесте — `test_*.json`.
- Steam: GodotSteam (GDExtension) — код в `game.gd` находит синглтон `Steam`, без него игра работает.
