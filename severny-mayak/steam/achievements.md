# Достижения Steam

Список совпадает с разделом `ach` в `godot/lang/src/*.js` (код ставит их через `G.achieve("ID")`).

| API name | RU | EN | Условие |
|---|---|---|---|
| NIGHT1 | Первая ночь | The first night | Пережить первую ночь. |
| BOARD | Всё сходится | It all adds up | Решить все разделы доски. |
| FAST | Успел | Just in time | Узнать правду во вторую ночь. |
| TRUTH | 23:58 | 23:58 | Восстановить удалённую запись. |
| END_A | Свет погас | The Light Goes Out | Рассказать правду. |
| END_B | Смотритель ждёт | The Keeper Waits | Никто не успевает. |
| END_C | Голос капитана | The Captain's Voice | Ответить как Лёва. |
| END_T | Настоящий свет | A Real Light | Найти настоящий финал. |
| SHARDS | Последняя глава | The last chapter | Собрать все осколки сказки. |
| CAUGHT | Палево | Busted | Попасться. |
| GHOST | Тише воды | Quiet as a mouse | Пройти, почти не привлекая внимания. |
| FLAGS | Знаток флагов | Flag expert | 10 из 10 во «Флажках». |
| MAP | Картограф | Cartographer | Собрать карту. |
| CIPHER | Капитанский шифр | Captain's cipher | Прочитать шифровку. |
| WORDS | Лупа | The lens | Собрать 30 слов. |
| END_P | Чужими руками | By Other Hands | Лёву находит следствие, и все узнают правду. |
| END_S | Тайна смотрителя | The Keeper's Secret | Лёву находит следствие, а правда остаётся тайной. |
| END_X | Вещдок | Evidence | Компьютер изымают на экспертизу. |

Скрытыми (hidden) в Steam стоит сделать END_B, END_C, END_T, END_P, END_S, END_X и TRUTH, чтобы не спойлерить.
