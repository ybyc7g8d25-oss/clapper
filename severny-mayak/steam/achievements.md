# Достижения для Steamworks

API-имя в Steamworks должно совпадать с тем, что в игре (`achieve('...')` в коде, список в `L.ach` в `game/js/lang/*.js`).

| API name | RU | EN | Условие |
|---|---|---|---|
| BOOT | Меня включили | Someone turned me on | Начать игру |
| NOTE | Записка | The note | Прочитать записку мамы |
| DIARY | Где живёт Пиксель | Where Pixel lives | Открыть дневник |
| GUARD | Сторож | The guard | Завершить pix_guard.exe |
| TRUTH | 23:58 | 23:58 | Восстановить удалённую запись |
| END_A | Свет на маяке погас | The Light Goes Out | Финал «правда» |
| END_B | Смотритель ждёт | The Keeper Waits | Финал «молчание» |
| END_C | Голос капитана | The Captain's Voice | Финал «ответить как Лёва» |
| END_T | Настоящий свет | A Real Light | Правда + все 7 осколков |
| SHARDS | Последняя глава | The last chapter | Собрать 7 осколков сказки |
| OFF | Только люди | Only people | 3 раза нажать «Выключить компьютер» |
| MAIL | Почтальон | Postman | Прочитать все письма |
| NG | Второй круг | Second round | Новая игра после любого финала |
| CAUGHT | Палево | Busted | Проиграть («Шнур выдернут») |
| GHOST | Тише воды | Quiet as a mouse | Дойти до финала, ни разу не подняв «Палево» до 35% |

Скрытыми (hidden) в Steam стоит сделать END_B, END_C, END_T, TRUTH, GUARD, чтобы не спойлерить.
