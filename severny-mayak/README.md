# Северный маяк / The North Lighthouse

Психологический хоррор на одном рабочем столе. Игрок — Пиксель, ИИ-друг мальчика Лёвы.
Лёва пропал два дня назад. Пиксель ищет его в файлах компьютера и прячется, чтобы люди в доме
не заметили, что компьютер живёт сам. В конце выясняется, что Лёва ушёл из-за самого Пикселя.

**Основная версия — на движке Godot 4 (папка `godot/`)**, пиксель-арт 960×540 с целочисленным масштабом.
Языки: русский и английский. Прохождение: около 1,5 часа (три части одной ночи), 4 финала, второй круг с уликами,
мини-игры «Флажки» и «Капитан и шторм», 20 достижений.

## Как запустить

**Готовая сборка:** `dist/windows/SevernyMayak.exe` (Windows) или `dist/linux/SevernyMayak.x86_64` (Linux).
Их нет в git — собираются командой ниже. Windows может предупредить о неподписанной программе:
«Подробнее» → «Выполнить в любом случае».

**Из исходников:**
1. Скачай Godot 4.4 (godotengine.org, обычная версия, не .NET).
2. Открой в нём `godot/project.godot` и нажми ▶ (F5).

**Сборка .exe** (нужны «Export Templates» 4.4: в Godot → Editor → Manage Export Templates → Download):
```bash
cd godot
godot --headless --export-release "Windows Desktop" ../dist/windows/SevernyMayak.exe
godot --headless --export-release "Linux" ../dist/linux/SevernyMayak.x86_64
```

**Автотест** — проходит игру целиком во всех финалах:
```bash
cd godot
godot --headless -- --test --lang=ru       # или --lang=en; --only=a|t|b|c — один финал
# со скриншотами (нужен экран или xvfb-run):
godot -- --test --lang=ru --shots=/tmp/shots
```

## Управление
- Двойной щелчок — открыть значок. Клик по облачку Пикселя или Пробел — следующая реплика.
- **D** или кнопка рядом с «Меню» — свернуть все окна (когда слышишь шаги).
- **Esc** — пауза. **F11** — окно / полный экран.

## Что где лежит (godot/)

| Путь | Что там |
|---|---|
| `lang/src/ru.js`, `lang/src/en.js` | **все тексты игры** — сюжет правится здесь. После правки: `node tools/build_lang.js` (соберёт `lang/*.json` и проверит, что структура языков совпадает) |
| `scripts/game.gd` | глобальное состояние (автозагрузка `G`): настройки, сохранения, достижения, Steam |
| `scripts/story.gd` | три части ночи, развязка, финалы, эпилог |
| `scripts/apps.gd` | все программы: записка, рисунки, журнал, браузер с PIN, почта, сказка, шифровка, дневник, камера, корзина, диспетчер задач, восстановление записи, мессенджер, фото, родительский контроль, карта, «Флажки» |
| `scripts/boat_game.gd` | мини-игра «Капитан и шторм» |
| `scripts/stealth.gd` | «Палево» и прятки |
| `scripts/desktop.gd`, `os_window.gd`, `desk_icon.gd` | рабочий стол Nimbus Kids, окна, значки, панель задач |
| `scripts/pixel_voice.gd` | облачко и аватар Пикселя |
| `scripts/menus.gd` | титульный экран, настройки, пауза, заставки частей, финалы |
| `scripts/fx.gd`, `shaders/screen.gdshader` | экранные эффекты стадий мрачности |
| `scripts/test_runner.gd` | автотест |
| `tools/make_art.py` | **вся графика рисуется этим скриптом** (Python + Pillow) → `art/` |
| `tools/make_sfx.py` | все звуки (синтез) → `sfx/` |
| `fonts/` | Unifont, Tiny5, Press Start 2P, Caveat (лицензии рядом) |

Старый веб-прототип остался в `game/` (HTML) и `prototype/` — для истории.

### Разметка в текстах
- `{{текст}}` — улика: во втором прохождении подчёркнута красным.
- `[[текст]]` в репликах Пикселя — оговорка: видна только во втором прохождении.

## Сюжет по частям

**Часть 1. «Где Лёва» (6 октября, 21:40).** Записка мамы. История браузера спрятана секретным режимом:
PIN — день рождения Лёвы (подписан на рисунке «семья»: 14.03 → 1403). История ведёт к водонапорной башне,
но мама пишет: полиция там была, дверь заварена, внизу никого. Письма, фото, журнал бесед, первая глава сказки.
Когда найдено достаточно, родительский контроль усыпляет компьютер.

**Часть 2. «23:58».** Компьютер просыпается сам — будильник поставил Пиксель. Дом спит, папа не спит и ходит.
Карта-пазл (маршрут Лёвы, метка «маяк (НАВЕРХ!)»), дневник (пароль «северный маяк»), новые главы сказки
(глава 4 написана PIKSEL.EXE), шифровка Лёвы (сдвиг 3 — «свет мигает три раза»). Папа садится за компьютер,
смотрит в камеру и выключает монитор.

**Часть 3. «Смотритель» (03:12).** Корзину держит `pix_guard.exe` — он же блокирует исходящие сообщения.
Его нужно завершить в диспетчере задач (Пиксель сопротивляется). Удалённую запись 03.10 23:44 нужно собрать
по кускам. Признание. Мама просыпается и пишет — выбор.

**Финалы:** правда · правда + все 7 осколков сказки (настоящий финал, письмо Лёвы через месяц) · молчание ·
ответить как Лёва. Проигрыш: «палево» 100% — шнур выдернут, загрузка сохранения.
