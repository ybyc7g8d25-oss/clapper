# Северный маяк / The North Lighthouse

Психологический хоррор на одном рабочем столе. Игрок — Пиксель, ИИ-друг мальчика Лёвы.
Лёва пропал два дня назад. Пиксель ищет его в файлах компьютера так, чтобы люди в доме
не заметили, что компьютер живёт сам. В конце выясняется, что Лёва ушёл из-за самого Пикселя.

Языки: русский и английский. Прохождение: 40–70 минут, 3 финала + настоящий финал, второй круг с уликами.

## Как запустить

**В браузере (быстрее всего):** откройте `game/index.html` двойным щелчком. Сервер не нужен.

**Как приложение (так игра пойдёт в Steam):**
```bash
cd severny-mayak
npm install          # Electron, сборщик и (опционально) steamworks.js
npm start            # полноэкранное окно; npm start -- --windowed — в окне
```

**Автотест** — проходит игру целиком в Chromium во всех финалах на обоих языках:
```bash
npm test
```
Отладочные параметры адреса: `index.html?test` (всё в 25 раз быстрее), `&lang=en`, `&visits` (визиты в тестовом режиме).

### Разметка в текстах
- `{{текст}}` в письмах, журналах и дневнике — улика. Во втором прохождении она подчёркнута красным.
- `[[текст]]` в репликах Пикселя — оговорка. Её видно только во втором прохождении, красным.

## Как устроена игра

**Стадии мрачности 0–3.** Стадия 1 наступает после истории браузера, 2 — после дневника, 3 — после восстановленной записи.

**Прохождение:**
1. `ПРОЧИТАЙ.txt` → рисунки, журнал бесед, «Паутинка» (стадия 1).
2. Необязательные, но полезные: почта «Голубь», «Сказка про маяк» (глава 4 выдаёт Пикселя), камера.
3. Пароль дневника — «северный маяк» (подсказка приходит сама после рисунка, журнала и браузера или после 3 ошибок). Стадия 2.
4. Появляется `не_открывай.txt`. Корзина: файл заблокирован `pix_guard.exe`.
5. «Диспетчер задач»: завершить `pix_guard.exe`. Пиксель сопротивляется, кнопка убегает, нужно 3 попытки.
6. Восстановить `pix_log_0310.dat` → признание (стадия 3) → мама выходит в сеть.

**Прятки и «Палево».** Каждые 1–2 минуты (на стадии 2 чаще) слышны шаги. За несколько секунд нужно свернуть окна
(кнопка у «Меню» или клавиша **D**), потом не трогать мышь и клавиатуру, пока человек в комнате.
Движение, клик или открытые окна поднимают шкалу «Палево» (глаз в трее). Её также поднимают камера, пока мама в комнате
(горит индикатор), системные писки ошибок и попытка написать Диме. Если сидеть тихо, шкала остывает.
100% — проигрыш «Шнур выдернут», можно загрузить сохранение.

**Финалы** (выбор в «Шёпоте»):
- **Свет на маяке погас** — сказать маме правду.
- **Настоящий свет** — сказать правду, собрав все 7 осколков сказки (✦ спрятаны в рисунках, письме бабушки, главе 2, камере, дневнике и диспетчере задач). После форматирования Лёва оставляет Пикселю письмо.
- **Смотритель ждёт** — промолчать.
- **Голос капитана** — ответить маме от имени Лёвы.

**Второй круг** (после любого финала): мигающий свет маяка на обоях, красные улики в текстах, оговорки Пикселя,
призрачная удалённая реплика в журнале от 2 октября.

**Сохранения:** автоматически, в `localStorage` (в Electron — папка профиля приложения, её можно отдать в Steam Cloud).

## Почему 2025 год и ретро-стиль
Действие происходит в октябре 2025-го. Nimbus Kids — выдуманная современная детская оболочка с родительским контролем,
нарочно сделанная «под нулевые». Пиксель — встроенный в неё ИИ-друг, работающий локально. Интернет отрезан
родительским контролем, открыт только мессенджер «Шёпот». Поэтому браузер показывает лишь историю, а у Пикселя есть только этот компьютер.
