# Северный маяк / The North Lighthouse

Психологический хоррор на одном рабочем столе. Игрок — Пиксель, ИИ-друг мальчика Лёвы.
Лёва пропал. Ночью Пиксель ищет его в файлах компьютера и прячется от родителей. Днём за компьютер садится
следователь и копирует файлы: они помогают найти Лёву, но и рассказывают, кто позвал его к башне.
Гонка: кто успеет первым — Пиксель, следствие или холод.

**Движок — Godot 4.4 (папка `godot/`).** Картинка рисуется в 480×270 и растягивается на весь экран
с чёткими пикселями. Языки: русский и английский. 7 финалов, второй круг с подсвеченными уликами,
побочное: «Флажки», «Капитан и шторм», рыбка Капитан, сны Пикселя. Устройство игры подробно — в [`DESIGN.md`](DESIGN.md).

## Как запустить

**Готовая сборка:** `dist/windows/SevernyMayak.exe` (Windows) или `dist/linux/SevernyMayak.x86_64` (Linux).
Их нет в git — собираются командой ниже. Windows может предупредить о неподписанной программе:
«Подробнее» → «Выполнить в любом случае».

**Из исходников:**
1. Скачай Godot 4.4 (godotengine.org, обычная версия, не .NET).
2. Открой в нём `godot/project.godot` и нажми ▶ (F5).

**Сборка .exe** (нужны «Export Templates» 4.4: в Godot → Editor → Manage Export Templates → Download):
```bash
cd godot
godot --headless --export-release "Windows Desktop" ../dist/windows/SevernyMayak.exe
godot --headless --export-release "Linux" ../dist/linux/SevernyMayak.x86_64
```

**Автотест** — проходит игру во всех финалах (a, t, b, c, p, s, x):
```bash
cd godot
godot -- --test --lang=ru                  # или --lang=en; --only=a — один финал
godot -- --test --lang=ru --shots=/tmp/s   # со скриншотами (нужен экран или xvfb-run)
```

## Управление
- Двойной щелчок — открыть значок. **Правый щелчок** — меню файла: открыть, спрятать в `.кэш`, стереть.
- **Tab** — доска улик. **Q** — лупа (подсвечивает слова, щелчок — слово в банк).
- **H** — дом: кто где в квартире (не забудь закрыть — он тоже на экране). **D** — свернуть всё (когда кто-то идёт). **W** — ускорить ночь.
- Пробел / Enter — следующая реплика Пикселя. **Esc** — пауза. **F11** — окно / полный экран.

## Как играется
- **Ночь** (22:00 → 06:00): читаешь документы, собираешь слова лупой, заполняешь доску улик. Родители ходят
  по дому: их видно, только если открыть дом (H), а так слышны лишь шаги и голоса. Кто-то идёт — сверни окна и замри: человек посмотрит на экран,
  и каждое забытое окно, свёрнутое окно на панели, включённая лупа поднимут «палево».
- **День**: следователь Орлов открывает файлы по очереди и копирует их («ДЕЛО» растёт).
  Когда ему звонят, он отворачивается, а его курсор уже стоит на следующем файле — можно успеть его убрать.
- **Шкалы:** ПАЛЕВО (заметят, что компьютер живой → шнур выдернут, переиграть), ДЕЛО (синяя — следствие
  ближе к Лёве; красная нить под ней — улики против Пикселя), ЛЁВЫ НЕТ N Ч (его время).

## Что где лежит (godot/)

| Путь | Что там |
|---|---|
| `lang/src/ru.js`, `lang/src/en.js` | **все тексты игры**. После правки: `node tools/build_lang.js` (соберёт `lang/*.json` и проверит, что структура языков совпадает) |
| `scripts/game.gd` | глобальное состояние (`G`): сохранения, часы Лёвы, файлы-улики и их ценность, доска, достижения, Steam |
| `scripts/night.gd` | ночь: время, события в доме, развязка, финалы |
| `scripts/day.gd` | день: следователь, копирование файлов, звонки, изъятие, «прокрутка будущего» после молчания |
| `scripts/docs.gd` | все программы и документы, спрятать/стереть, папка `.кэш` |
| `scripts/board.gd` | доска улик |
| `scripts/stealth.gd` | палево, визиты, проверка экрана взглядом, шаги, которых нет |
| `scripts/madness.gd` | нарастающие галлюцинации |
| `scripts/boat_game.gd`, `fish_tank.gd` | «Капитан и шторм», аквариум |
| `scripts/house.gd` | полоска дома с людьми |
| `scripts/desk.gd`, `os_window.gd`, `desk_icon.gd`, `hud.gd` | рабочий стол, окна, значки, строка статуса и кнопки |
| `scripts/voice.gd` | реплики и цель Пикселя |
| `scripts/menus.gd` | титул, настройки, пауза, газета ночи, протокол дня, отчёты, финалы |
| `scripts/main.gd`, `shaders/` | вывод 480×270 на весь экран, курсор |
| `scripts/test_runner.gd` | автотест |
| `tools/make_art.py` | **вся графика рисуется этим скриптом** (Python + Pillow) → `art/` |
| `tools/make_sfx.py` | все звуки (синтез) → `sfx/` |

Старые версии — в `old/godot-v2/` (v2 на Godot), `game/` и `prototype/` (веб-прототип).

### Разметка в текстах
- `<<id|слово>>` — ключевое слово: лупой его можно забрать в банк слов.
- `{{текст}}` — улика: во втором прохождении подсвечена красным.
- `[[текст]]` в репликах Пикселя — оговорка: видна только во втором прохождении.
